# 🖼️ Image Carousel / Slider

A responsive and interactive image carousel built using **HTML5, CSS3, and JavaScript**. It allows users to navigate through images using Next and Previous buttons, automatically rotates slides, and pauses the slideshow when hovering over the carousel.

## 🚀 Features

- 📸 Displays 5 beautiful image slides
- ⏭️ Next and Previous navigation buttons
- 🔄 Automatic slide rotation every 3 seconds
- ⏸️ Pauses automatic rotation on hover
- 🔵 Clickable slide indicators
- 🎨 Smooth CSS transitions
- 📱 Responsive design for mobile and desktop
- 🔁 Automatically loops through all slides

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (DOM Manipulation and Events)

## ⚙️ How to Run

1. Clone this repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Open the project folder in VS Code.

3. Make sure `index.html`, `style.css`, and `script.js` are in the same folder.

4. Open `index.html` in your browser, or use the Live Server extension in VS Code.

5. Use the navigation buttons or slide indicators to explore the images.

**Note:** An internet connection is required to load the externally hosted images.
